# Incoming Requests

## Purpose
Tutor sees all session requests from parents.

## Wireframe
```text
+----------------------------------+
| Back                             |
| Incoming Requests                |
+----------------------------------+
| Request 1                       |
| Parent: Grace O.                |
| Subject: Maths                  |
| Day: Tuesday 6pm                |
| Status: Pending                 |
| [Review]                        |
| goes to: incoming_requests      |
|                                  |
| Request 2                       |
| Parent: Musa B.                 |
| Subject: Physics                |
| Day: Thursday 5pm               |
| Status: Pending                 |
| [Review]                        |
| goes to: incoming_requests      |
+----------------------------------+
| [My profile]                    |
| goes to: tutor_my_profile       |
+----------------------------------+
```

## Notes
- Tutor reviews parent requests from a simple list.
- Primary action is to review each request.
