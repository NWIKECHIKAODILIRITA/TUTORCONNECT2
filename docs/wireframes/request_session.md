# Request Session

## Purpose
Parent sends tutoring request to selected tutor.

## Wireframe
```text
+----------------------------------+
| Back                             |
+----------------------------------+
| Request a session                |
+----------------------------------+
| Tutor: Ada Adebayo               |
| Subject: Maths                   |
| Preferred day                   |
| [Select day]                    |
| Preferred time                  |
| [Select time]                   |
| Location                        |
| [Online / Home / School]        |
| Budget                          |
| [N5,000 / hour]                 |
| Student details                 |
| [Class / Level]                 |
| Message to tutor                |
| [I need help with algebra...]   |
+----------------------------------+
| [Send Request]                  |
| goes to: my_session_requests    |
+----------------------------------+
```

## Notes
- One primary CTA: Send Request.
- No payment or chat flow in MVP.
