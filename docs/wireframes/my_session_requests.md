# My Session Requests

## Purpose
Parent views request statuses after sending session requests.

## Wireframe
```text
+----------------------------------+
| Back                             |
| My Requests                      |
+----------------------------------+
| Request 1                       |
| Maths - Ada Adebayo             |
| Status: Pending                 |
| Sent: 12 Aug                    |
| [View details]                  |
| goes to: my_session_requests    |
|                                  |
| Request 2                       |
| Physics - Daniel Okafor         |
| Status: Approved                |
| Sent: 10 Aug                    |
| [View details]                  |
| goes to: my_session_requests    |
+----------------------------------+
| [Find another tutor]            |
| goes to: search_tutors          |
+----------------------------------+
```

## Notes
- Parent can check if request is pending, approved, or rejected.
- Primary action is to find another tutor or review status.
