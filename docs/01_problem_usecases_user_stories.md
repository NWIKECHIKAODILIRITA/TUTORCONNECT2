# TutorConnect Nigeria - Problem, Use Cases, and User Stories

## 1) Problem Statement
Parents in Nigeria find it hard to locate trusted tutors that match their child’s subject, preferred time, location, budget, and experience level. At the same time, skilled tutors struggle to connect with students who need their help. There is a need for a simple platform that makes tutor discovery and booking easier and safer for all users.

## 2) Solution Summary
TutorConnect Nigeria is a simple MVP platform that helps parents find tutors by subject, location, time, budget, and experience. Tutors can create profiles and respond to student booking requests. Admins review and approve or reject tutor profiles and booking requests to keep the platform trustworthy and organized.

## 3) Use Cases

### Parent
- Create an account as a parent.
- Search for tutors by subject, location, time, and budget.
- Apply filters to find tutors that match their needs.
- View tutor profiles with basic information and experience.
- Send a session request to a tutor.
- View the status of their booking requests.
- Receive updates when a request is approved or rejected.

### Tutor
- Create an account as a tutor.
- Create and update a tutor profile.
- Add subject expertise, location, availability, and experience.
- See booking requests from parents.
- Accept or reject session requests based on availability and fit.
- View user requests and manage their own schedule.

### Admin
- View all users in the system.
- View all tutor profiles.
- Review new tutor applications.
- Approve or reject tutor profiles.
- View booking requests submitted by parents.
- Approve or reject booking requests.
- Keep the platform safe and organized by managing user and request activity.

## 4) User Stories

### Parent
- As a parent, I want to search for tutors by subject and location, so that I can find a tutor near me.
- As a parent, I want to filter tutors by time and budget, so that I can choose a tutor that fits my schedule and price.
- As a parent, I want to view tutor profiles, so that I can check their subject, experience, and availability.
- As a parent, I want to send a session request, so that I can ask a tutor for help.
- As a parent, I want to see whether my request is approved or rejected, so that I know the next step.

### Tutor
- As a tutor, I want to create my profile, so that parents can learn about my subjects and experience.
- As a tutor, I want to add my availability, so that parents know when I can teach.
- As a tutor, I want to view booking requests, so that I can know which students want my help.
- As a tutor, I want to accept or reject requests, so that I can manage my teaching schedule.
- As a tutor, I want to update my profile details, so that I can keep my information accurate.

### Admin
- As an admin, I want to view all users, so that I can manage platform access.
- As an admin, I want to review tutor profiles, so that I can approve only trusted tutors.
- As an admin, I want to approve or reject booking requests, so that I can maintain order and quality on the platform.
- As an admin, I want to see all booking activity, so that I can monitor platform use.
- As an admin, I want to manage user and request records, so that the platform stays organized and reliable.

## 5) Out of Scope for MVP
The MVP will not include:
- Online payments or bank transactions
- In-app chat between parent and tutor
- Tutor or parent ratings and reviews
- Video calls or live lesson sessions
- AI-based matching or recommendations
- Messaging, notifications beyond basic request status
- Advanced scheduling automation
- Mobile app development
- Full production security, compliance, or large-scale scaling features

This MVP is limited to tutor profiles, search and filters, session requests, admin approval or rejection, and viewing users and booking requests.
