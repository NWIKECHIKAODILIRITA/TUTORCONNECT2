# TutorConnect Nigeria Tech Stack

## 1) Frontend
- HTML5 for page structure and content
- CSS3 for layout, spacing, responsive design, and styling
- JavaScript later for interactivity, form handling, and UI behavior

## 2) Backend
- Python with FastAPI for API development
- FastAPI will be used later when the MVP moves from static pages to working backend logic

## 3) Database
- PostgreSQL for storing users, tutor profiles, session requests, and admin records

## 4) Why this stack fits a student full-stack MVP
- Simple to learn for students: HTML, CSS, Python, and SQL are easy to understand
- Fast setup for a small project without extra complexity
- Clear separation between frontend structure, backend logic, and database storage
- Good for building a scalable MVP while keeping the project manageable
- Fits the project goals: tutor search, profile management, session requests, and admin review

## 5) What we build in THIS module vs later modules
### This module
- HTML-only pages for the MVP screens
- Simple page structure and content layout
- Navigation between pages
- Basic form layouts and screen flow

### Later modules
- CSS3 styling and responsive mobile-first design
- JavaScript for form validation and interactions
- Python + FastAPI backend APIs
- PostgreSQL database setup and data storage
- User, tutor, and admin workflows connected to real data

## Summary
This stack is a practical student-friendly full-stack setup: HTML5 + CSS3 + JavaScript for the frontend, Python + FastAPI for the backend, and PostgreSQL for the database. It supports a simple MVP that can grow step by step without changing the core technology choices.
